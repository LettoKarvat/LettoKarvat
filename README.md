Os projetos que venho reunindo no portfólio envolvem:

- Sistemas de força de vendas e integrações com Winthor/Oracle.

Entre as tecnologias presentes nesses projetos estão **React, TypeScript, Node.js, Express, SQL, Oracle, PostgreSQL, SQLite e Python**.

## Código público

### [DevSweep](https://github.com/LettoKarvat/devsweep)

Ferramenta para Windows que encontra dependências e caches de desenvolvimento, permite revisar as pastas e envia as selecionadas à Lixeira. Feita em Python, com interface Tkinter e integração com APIs do Windows.

A ideia e a definição inicial do problema são minhas. A implementação inicial contou com assistência de IA, conforme registrado no repositório.

### [Radar de Ofertas](https://github.com/LettoKarvat/radar-de-ofertas)

Site estático de ofertas gerado por um fluxo de curadoria automatizada. É um exemplo complementar de publicação de conteúdo; o repositório do site não representa todo o código do robô responsável pela coleta e curadoria.
